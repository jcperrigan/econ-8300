Overview

In this activity you will work through three related designs:

  1. A basic event study with a single treated unit observed before and after a policy.
  2. A 2x2 difference-in-differences setup with a treated and a control group.
  3. An event-study with leads and lags in a staggered-adoption panel.

The outcome in all three parts is the organ donation rate per million residents. The policy is a donor registration reform meant to increase organ donation. It’s similar to the socviz dataset but simulated to make the timing treatment clearer.

Learning goals

By the end of this activity, you should be able to:

  • estimate and interpret a basic DiD model
  • explain the parallel trends assumption
  • estimate an event-study model with leads and lags
  • use pre-treatment coefficients to support parallel trends (or not)

0.3 Staggered-adoption panel for leads/lags

set.seed(8302)

adoption_years <- tibble(
  state = c("Arizona", "Colorado", "Florida", "Georgia", "Iowa", "Kansas", "Nevada", "Utah"),
  adopt_year = c(2002, 2004, 2006, 2008, Inf, Inf, 2005, 2007)
)

staggered_data <- expand_grid(
  state = adoption_years$state,
  year = 1998:2010,
  hospital = 1:20
) %>%
  left_join(adoption_years, by = "state") |>
  mutate(
    treated_ever = if_else(is.finite(adopt_year), 1, 0),
    event_time = if_else(is.finite(adopt_year), year - adopt_year, NA_real_),
    treated_now = if_else(is.finite(adopt_year) & year >= adopt_year, 1, 0),
    state_effect = case_when(
      state == "Arizona"  ~  1.2,
      state == "Colorado" ~  0.6,
      state == "Florida"  ~  0.3,
      state == "Georgia"  ~ -0.4,
      state == "Iowa"     ~  0.8,
      state == "Kansas"   ~ -0.2,
      state == "Nevada"   ~  0.1,
      state == "Utah"     ~  1.0
    ),
    common_trend = 0.28 * (year - 1998),
    treatment_effect = if_else(treated_now == 1, 2.5 + 0.15 * pmax(event_time, 0), 0),
    donation_rate = 19 + state_effect + common_trend + treatment_effect + rnorm(n(), 0, 1.1)
  )

Task 4. Why is this design weak for causal inference?

Give one reason why a single-group before/after event study is vulnerable to bias.

Your answer:

A single group before/ after comparison can’t separate the policy effect from all the other stuff that changed over time. Maybe donation rates were already rising because of public awareness or other things, we might wrongly attribute those changes to the donor registration reform.

es_results <- tidy(mod_es) %>%

Your answer:

It should be the case that the lead coefficients should mostly be close to zero, which supports parallel trends.

the lag coefficients should become positive after treatment, which indicates higher donation rates after the reform.

It relates back to basic DiD because the single DiD interaction coefficient is replaced with a sequence of those event time specific interaction coefficients. DiD is an average post treatment effect while having a beta for each period shows the path over time.

We can say what should be the case because the data are simulated.

Wrap-up

In 3-5 sentences, summarize the differences among:

  • a basic event study,
  • a 2x2 DiD design,
  • an event-study with leads and lags.

Your answer:

A basic naive event study compares one unit before and after an event but it can’t rule out other changes over time. A 2x2 DiD design makes this better because it adds a control and differences out common time changes (relies on parallel trends assumption). An event study with leads and lags is a more flexible version of DiD that estimates a separate treatment effect for each period relative to a baseline and uses pre treatment coefficients to check support for the parallel trends assumption.
