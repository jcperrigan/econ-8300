3. Law of Large Numbers

Task 4: Convergence of Sample Means

Generate two samples, one of size 10 and one of size 5,000.

Each of these samples should draw from the

# Generate increasing sample sizes
n <- seq(10, 5000, by = 10)
means <- sapply(n, function(i) mean(rnorm(i, 50, 10)))



plot(n, means, type = "l",
main = "Law of Large Numbers",
xlab = "Sample size",
ylab = "Sample mean")
abline(h = 50, col = "red")

Questions
